# 心电一致性与联合稳健性复算

Python 3.13标准库即可运行，无第三方依赖。程序从原始ptbxl_database.csv、12sl_statements.csv及statement_mappings.zip读取记录与发布类别，建立三目标原状态，完成固定人群与患者索引、配对、疑似情景、分层、Wilson区间、联合标签压力及优先复核。

在ecg-label-consistency目录使用PowerShell：

```powershell
uv run --no-project --python 3.13 solution/script/复算心电一致性.py --task . --out solution/script/data
```

统计结果.json保存主队列未舍入结果；患者配对.csv与记录配对.csv分别保存患者索引和全部符合条件记录，CSV记录号包含表头且不等于物理文本行号。联合稳健性.json保存原组合、提案、六项族区间、所有压力精确端点、匿名实现清单、配对差值及联合最少人数证书。

单项有限预算采用四来源格翻转人数穷举；C1及同情景配对差值按原两侧三位组合计数枚举所有有界可达状态，保留精确有理数与实现路径。联合最少人数由可行匿名证书和逐名额排除下界共同验证，不需要优化器。

名额5和容量15%为业务情景参数。状态、端点、匿名对象与人数下界均由原件计算，不硬编码派生结果；程序不覆盖输入，不改原标签，情景不能作为实际纠错或真实错误率估计。
