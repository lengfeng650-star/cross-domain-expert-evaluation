# 跨领域专家模型评测试题

本数据集收录10道专家模型评测试题，包含医疗4题、法律3题、金融3题。每题提供任务要求、输入材料、评分标准和参考成果，覆盖临床复核、公共卫生服务评价、法律尽调、交易审查、资金分析和基金研究。

题目以一项完整业务委托为单位。作答需要阅读病历、报告、法规、公告、表格或原始信号，核对事实与时点，完成计算或证据比较，并提交能够复核的业务成果。评分同时评价结论、依据、计算、判断边界和交付要求。

## 逐题介绍

### 医保用药疑点的药学复核

**考察范围：**核对病历、药品说明书和医保目录，判断适应证、给药途径、剂量、疗程与支付范围。将已记载的用药事实、相互矛盾的记录和需补充的证据分别列明。

**出题思路：**材料同时包含病程记录、事后说明和扫描件，部分剂量、停药日期及费用明细不完整。题目考察能否发现记录差异，完成有出处的复算，并给出申诉、认扣或补证的药学意见。

[题目与材料](data/tasks/medicine/medication-reimbursement-review/question.md)

### 再次瓣膜手术的排台与抗凝复核

**考察范围：**综合瓣膜影像、出血与贫血记录、抗凝用药及排台变化，复核再次手术的推进条件、围术期交接和患者沟通。

**出题思路：**将检查时间、报告时间、实际给药时间和拟执行方案放在同一病例中，要求按当前及备用排台核算停药间隔、药量与泵速，考察跨专业证据整合和条件化决策。

[题目与材料](data/tasks/medicine/valve-surgery-anticoagulation/question.md)

### 心电自动判读的标签一致性与优先复核

**考察范围：**比较十二导联心电的归档参考标签与自动判读结果，完成患者索引、四状态映射、配对统计、区间估计、八例波形审阅和优先复核名单评价。

**出题思路：**三种目标共用标签重分类名额，复核名单又受到容量限制。题目要求给出端点实现清单和最少人数依据，考察统计可复算性，以及归档一致性与临床性能证据的区别。

[题目与材料](data/tasks/medicine/ecg-label-consistency/question.md)

### 麻疹与MMR服务复盘及优先序审查

**考察范围：**核对英格兰六地麻疹监测与接种覆盖资料，分析GP年度构成、固定补种队列、覆盖率取整误差和地区服务优先序。

**出题思路：**将公布覆盖率、可比GP集合和个人记录变化分别评价，用反例、人数界限和转移表检验会议提案，考察能否避免将汇总变化直接解释为诊所表现或不同接种人数。

[题目与材料](data/tasks/medicine/measles-mmr-service-review/question.md)

### 数据中心资产权属与许可尽调

**考察范围：**审查东阳光交易披露中的资产权属、租赁、经营许可、建设验收、历史交易及权利限制，形成事项台账、复算和交割条件。

**出题思路：**多期法律意见与交易公告在报告期、出具日和交易状态上各有范围。题目考察扫描材料读取、跨文件核对，以及将法律风险落实为所需凭证、责任方和决策条件的能力。

[题目与材料](data/tasks/law/property-title-permit-review/question.md)

### 控制权交接后的合作权益与关联交易审查

**考察范围：**围绕上海莱士控制权交接，核对主体责任、表决权安排、合作及经销权利、业绩承诺、分红与关联交易程序。

**出题思路：**股份登记、控制认定、合同生效、预算与实际执行并非同一事项。题目要求结合各自时点和币种复算财务披露，判断现有材料能够支持的权利主张及后续行动。

[题目与材料](data/tasks/law/post-acquisition-cooperation-review/question.md)

### 重整普通债权受让的交易边界审查

**考察范围：**从潜在买方立场评价广田集团重整普通债权的清偿权益，区分继续调查、报价和付款交割的条件，测算整笔与部分受让的资源边界。

**出题思路：**在交易对手、目标债权与价格尚未确定时，要求依据重整计划、执行披露和诉讼材料形成有条件的意见，考察总量测算与单笔权利确认的边界，以及证据缺口对交易安排的影响。

[题目与材料](data/tasks/law/restructuring-claim-transfer/question.md)

### 收购配套募集资金缺口复算

**考察范围：**复算东数一号收购相关的可使用资金、资金需求、总缺口及补流偿债缺口，核对现金流转换参数、舍入差异和资金来源条件。

**出题思路：**把汇总表能否追算与融资资金能否实际动用分开核验，比较足额配募、债券未发行及配募不足时的资金压力，考察对预测、授信和已取得现金的区分。

[题目与材料](data/tasks/finance/financing-gap-review/question.md)

### 混合基金业绩基准与相对财富审查

**考察范围：**研究四只混合基金的基准定义、份额类别、近期业绩与长期财富路径，估算基准回撤及基金相对基准的财富回落。

**出题思路：**要求在同日基金与基准累计增长率上计算相对财富，并分别寻找各自的峰谷区间。题目考察图示证据读取、期间一致性和指标解释，避免用增长率差或独立回撤之差替代财富比值。

[题目与材料](data/tasks/finance/fund-benchmark-review/question.md)

### 基础设施REIT现金流与资产估值复核

**考察范围：**核对四只基础设施REIT两期合并及基金个别现金流、可供分配金额调节和实际分派，并复算两项目十年现金流窗口的折现敏感性。

**出题思路：**以可编辑工作簿连接原表、复算、差额与会议意见，考察财务主体、收益期间、调增调减符号和估值范围。局部十年窗口须与正式评估结果、基金净资产及份额市值分别解释。

[题目与材料](data/tasks/finance/reit-cashflow-valuation-review/question.md)

## 文件组织与使用

`meta/questions.jsonl`是10题索引，每行一题，包含领域、题目、考察范围、出题思路、任务正文和附件路径。`meta/dataset.json`记录题量及领域分布。

`data/tasks/`按领域和题目组织。每题的`question.md`为任务正文，`input_files/`为解题材料，`rubrics.json`为评分标准，`solution/`为参考成果。心电题另附复算程序与相应数据。运行环境及命令见该题的参考成果目录。

作答时使用题目规定的材料、信息截止日和联网范围。评分及参考成果用于结果比较，实际交付形式和计算要求以各题正文为准。各题保留原评分权重和扣分项，跨题比较前应按各题正向权重合计统一分数尺度。
